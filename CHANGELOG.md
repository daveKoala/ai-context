# Changelog

## v0.1

An aggregation of recent learnings about working with AI coding agents.

### Why

Every agent session starts with no knowledge of how I work. Without written context, I end up repeating the same expectations, correcting the same habits, and getting inconsistent results between sessions and tools. Writing it down makes those expectations explicit, consistent and versioned, and gives me something concrete to test and improve.

### Variables

The results depend on more than these files. Each of the following can change behaviour, sometimes significantly:

- **Model and model version.** New releases can respond differently to the same instruction.
- **Thinking or effort level.** The same model can behave differently at different levels.
- **Tool and tool version.** Claude Code, Cursor, Codex and others load and apply context differently.
- **These files.** Identified by the repo commit.
- **The task.** Some rules only matter for some kinds of work.

Any finding is only meaningful alongside the variables it was observed under.

### Status

I'm no Luddite, but I don't think this approach has been tested enough yet. I'll keep a record of findings in `FINDINGS.md`, so changes here are based on evidence rather than impressions.
